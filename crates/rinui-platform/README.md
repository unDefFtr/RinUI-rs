# rinui-platform

Platform capabilities and configuration persistence for [rinui-rs](https://github.com/unDefFtr/rinui-rs). Provides platform and appearance types, per-application configuration directories, and JSON-backed configuration stores. The crate does not require Qt.

Use `rinui-platform = "0.1.0-alpha.1"` in your `[dependencies]`. For the Qt Quick host and embedded RinUI QML components, use `rinui-host`.

Project guides are available in the [RinUI-rs documentation](https://rinui-rs.undef.work/).
